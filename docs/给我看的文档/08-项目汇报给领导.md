# 08 · 项目汇报（给领导）

> 生成时间：2026-11-14　｜　读者：非技术背景 / 管理层
> 所有数字均来自本仓库实测或代码事实，未验证项已标注。

---

## 一、这个项目在做什么

把工厂工位的监控视频，变成一份**能自动看懂的作业记录**：

- 画面里叠出工人和左右手的骨架、手的位置；
- 自动把整段视频切成一个个 **SOP 工序片段**（放件、装件、打螺丝……）；
- 每段显示：这一步是什么、左手在做什么、右手在做什么、用的什么工具、对什么工件；
- 底部一条时间轴，三道轨道（工序 / 左手 / 右手）同步，可以点着看。

最终形态对标一份已有的参考实现（10 分钟演示视频，右侧 4 张卡片 + 三条轨道）。

## 二、现在到什么程度

**已经能演示。** 打开网页就能看到：骨架贴在视频画面上、左右手框跟随、三道轨道时间轴联动、右侧卡片随播放更新。

| 能力 | 状态 |
|---|---|
| 人体 + 左右手关键点（骨架） | ✅ 已完成，骨架已烧进视频 |
| 左右手框、手部小图裁剪 | ✅ 已完成（全片 600 帧只需 4 秒） |
| 三道轨道统一时间轴 | ✅ 已完成，共用一根播放头 |
| 动作语义卡片（SOP/动作/左手/右手） | ⚠️ 只有前 30 秒试点数据 |
| 真正的 SOP 工序切分（不等长片段） | ❌ 未做（当前是固定 3 秒窗口） |
| 轻量模型 + 设备端部署 | ❌ 未做 |

一句话：**"看得见"这层做完了，"看得懂"这层刚起步。**

## 三、技术路线（三段式）

```text
① 感知（本地、免标注）
   人体检测 + 全身/手部骨架 + 手周围小图
   ↓
② 语义（云端大模型，只做"教师"）
   把每个片段归类到 SOP 步骤，并描述左右手在做什么
   ↓
③ 部署（本地轻量模型，只做"学生"）
   用教师产出的标注训练一个小模型，跑在设备上
```

**为什么要有"教师→学生"两段？**
大模型看得懂，但慢、要联网、上不了产线设备；小模型能上设备，但需要大量标注。
所以让大模型先把标注做出来，人只改错，再用这些标注训练小模型。
**结论：这是把"人工标全部"降成"人工改一部分"的唯一省钱办法。**

## 四、三个关键设计决定（省钱 / 能落地）

| 决定 | 好处 | 代价 |
|---|---|---|
| **不标物体框**，改用手周围小图 | 换产线时一个框都不用重标，这才是"傻瓜式换线" | 换来几毫秒算力 |
| **骨架烧进视频**，不在网页上实时画 | 不会出现画面和骨架对不齐 | 改参数要重新渲染约 2 分钟 |
| **小模型只吃数值 + 小图**，不进大模型 | 能上设备、能多路、能离线 | 需要先有一批教师标注 |

## 五、算力和成本（实测，非估算）

**单路每帧耗时（纯 CPU，未用显卡）**：人体检测 7.3 ms + 骨架 18 ms ≈ **25.6 ms/帧**。

| 场景 | 需要的算力 |
|---|---|
| 单路 10 次/秒 | 约占 1/4 核 |
| **4 路 5 次/秒** | **约 0.5 核** |
| 8 路 5 次/秒 | 约 1 核 |

→ **算力不是瓶颈**，现有设备跑 2~4 路没问题（桌面实测；目标设备需再验证，通常慢 2~4 倍）。

**大模型调用费（按次计）**：
- 2 分钟视频、每 3 秒一次 = **40 次调用**
- 10 分钟整片、每 1 秒一次 = **599 次调用**

建议先用 40 次跑通验收，再决定要不要加密。

**标注成本**：
- 只需标"SOP 段落"，不用标框；
- 教师先预填，人只改错的段（预计降到原来的 20%~30%，**此比例待实测**）。

## 六、风险（需要提前知道）

| 风险 | 影响 | 现状/对策 |
|---|---|---|
| **参考视频与本项目视频可能不是同一工位/同一产品** | 直接照抄 SOP 表会导致识别错乱 | **必须先确认**，这是第一道坎 |
| AI 生成的片段标注可能前后不一致 | 学生模型学到噪声 | 已规划：合并相邻同段、最短时长约束、人工抽检 |
| 骨架精度受机位限制 | 部分时刻手部关键点会散 | 已加过滤，剔除最差的约 18% 帧；仍不完美 |
| 现有标注粒度偏粗（只有"拧螺丝/用螺丝刀"两类） | 无法校验 10 步 SOP | 需重标或接受"部分步骤可校验" |
| SOP 步骤表还没定 | 后面所有事都卡在这里 | 下一步第一件事 |

## 七、需要领导支持的三件事

1. **确认工位**：参考实现那套产品和我们的视频是不是同一套？（一句话就能定，但决定 SOP 表能不能照抄）
2. **标注人力**：第一批约 20~30 段 SOP 标注 + 教师结果抽检（预计 1~2 人日，待实测）。
3. **大模型 API 额度**：先跑 40 次调用做验收（2 分钟视频）。

## 八、下一步计划（按依赖顺序）

| 阶段 | 产出 | 依赖 |
|---|---|---|
| P0 | SOP 步骤表（10 步 + 转移关系 + 兜底类） | 领导确认工位 |
| P1 | 教师跑 2 分钟视频 → 首版分段 | API 额度 |
| P2 | 人工校正 + 训练小模型（第一版） | 标注人力 |
| P3 | 网页接入真实分段（三轨真正对齐） | P1 |
| P4 | 设备端部署验证（帧率/内存/多路） | 目标设备 |

**建议先做 P0**：半天工作量、零 API 成本，但后面全部依赖它。
