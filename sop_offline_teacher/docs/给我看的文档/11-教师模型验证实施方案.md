## 二、三个关键发现（直接决定方案）

### 发现 1：GT 覆盖了"证据齐全"的那 120 秒 → **不用重跑任何推理就能做首次带真值评估**

实测对齐：把 `v2_5m_7m_h264.mp4` 的 12/45/90/115 s 帧与 `v2.mp4` 的 `300+t` 帧对比，
灰度平均差 **3.3–6.0**（等于同一帧的重编码差异），而错开 1–4 s 时差值为 10–27。

```
clip 时间 t  →  v2.mp4 时间 300 + t     （±0.5 s）
```

落在 300–420 s 里的 GT 共 **11 段 / 62.7 s**，而且包含最难也最有价值的几类：

| v2 时间 | 片段内时间 | 时长 | 行为 |
|---|---|---|---|
| 305.81–308.05 | 5.81–8.05 | 2.24 s | 取镜座 |
| 312.93–313.29 | 12.93–13.29 | 0.36 s | 取上盖（**可疑**） |
| 314.85–315.61 | 14.85–15.61 | 0.76 s | 取上盖（**可疑，且嵌套在下一段里**） |
| 314.85–319.52 | 14.85–19.52 | 4.68 s | 取镜座 |
| 321.96–322.73 | 21.96–22.73 | 0.76 s | 取镜座（**可疑**） |
| 329.64–341.61 | 29.64–41.61 | 11.96 s | 系扎带 |
| 343.29–350.53 | 43.29–50.53 | 7.24 s | 装上盖 |
| 353.21–357.49 | 53.21–57.49 | 4.28 s | 装密封塞 |
| 373.17–400.93 | 73.17–100.93 | 27.76 s | 紧固 |
| 405.65–408.01 | 105.65–108.01 | 2.36 s | 取镜座 |
| 413.49–413.77 | 113.49–113.77 | 0.28 s | 取上盖（**可疑**） |

### 发现 2：工序是严格循环，共 6 个周期

紧固段起点：`104.4 / 184.5 / 269.6 / 373.2 / 443.7 / 534.3` → **周期 70.6–103.5 s（均值 86 s）**

固定顺序：

```
取镜座 → 取上盖 → 装上盖 → 装密封塞 → 紧固（→ 偶发：系扎带）→ 下一件
```

→ 这给了两个白送的约束：**① 可以做"循环完整性"指标（每周期步数）；② 可以按周期做训练/验证切分，避免数据泄漏。**

### 发现 3：标签有两处必须先定规则，否则会污染训练

| 问题 | 具体 | 影响 |
|---|---|---|
| **嵌套** | 314.85 s「取上盖 0.76 s」完全嵌在「取镜座 4.68 s」里 | 单标签分类器无法同时满足，必须定优先级 |
| **过短** | 38 段里有 **8 段 ≤0.8 s**（7 段是"取上盖"，最短 0.20 s） | 0.2 s 短于人连按两次键的间隔，**极可能是双击误触**；若当正样本训练，模型会学到噪声 |
| 缺兜底类 | 没有 `idle` / `unknown` | 空隙段现在是"没有事件"，模型需要显式负类 |

## 三、四阶段方案（每阶段都有产物与验收）

### P0 · 标签与窗口基座 —— ✅ 已完成（2026-11-15）

按你确认的三条规则实现：

| 规则 | 落地方式 |
|---|---|
| 短段 ≤0.8s **算真实动作** | 保留为训练正样本，只打 `short=true`；窗口用**整段**（不足 2s 不扩边），单独统计准确率 |
| 嵌套**长段优先** | 被更长段完全包含的段打 `nested_short=true`，时间归属长段，**不生成独立窗口**（实测仅 1 段：314.85–315.61 取上盖） |
| idle 只取距事件 >2s 的中段 | 先把所有事件区间并集，空隙两侧各让 2s，再取 2s 窗口 |
