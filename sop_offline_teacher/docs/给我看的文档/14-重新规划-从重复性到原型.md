## 二、你的想法：方向对，但有一个坑

### 2.1 对在哪里

你说的本质是 **"用重复性发现动作原型"**，学术上叫：

| 你的说法 | 专业名称 |
|---|---|
| 「重复做的动作，输出会重复」 | **动作原型发现 (action discovery / motif discovery)** |
| 「用权重的方法」 | **TF-IDF / 互信息加权**（抑制"双手""工件"这类到处都出现的词） |
| 「大量采集找重复性很高的输出」 | **无监督聚类 / 序列模式挖掘 (PrefixSpan, SPADE)** |

这条路的最大好处：**不需要给每个步骤写判据，也不需要 VLM 逐段判定**。
只要机器把「重复出现的运动模式」聚出来，人工只需要给 **K 个簇**各起一个名字。

### 2.2 坑在哪里（必须避免）

**"重复率最高的输出"往往是废话，不是步骤。**

例：模型最容易重复的描述是「双手持工件」「操作工件」——它们在**所有**步骤里都出现，
重复率最高，但完全不区分步骤。所以要按 **判别性** 加权，而不是纯频次：

```
权重 = 该描述在"这一簇里出现的比例" ÷ 它在"所有簇里出现的比例"
      （这就是 TF-IDF 的思路；频次高但到处都有的词，权重会被压到很低）
```

## 三、实测证据（我刚做的，0 次 API 调用）

新增 `scripts/discover_motifs.py`：**完全不用大模型**，只用 10 Hz 骨架的运动特征
（左右手速度、手部开合度、两手间距、手的高度，全部按人体高度归一化），
用本地变化点检测切段，再对每段做 k-means 聚类。

| k（簇数） | 纯度（含空闲段） | 纯度（只算 GT 有标注的段） |
|---|---|---|
| 4 | 55.6% | 57.1% |
| 6 | 63.0% | 64.3% |
| **8** | 66.7% | **78.6%** |
| 10 | 70.4% | 71.4% |

**k=6 时的一个簇特别说明问题**：

```
簇 4：4 段 → 81-84s, 84-89s, 89-92s, 92-102s     GT 构成：紧固×4
```

**这 4 段全部是"紧固镜子镜座"，被纯运动特征自动聚到了一起**——没有任何标注参与。
说明"重复性"这条信号是真实存在的，而且**长动作几乎能被无监督分开**。

同时也能看到它的边界：`空闲×6`、`装上盖×2 取上盖×1 取镜座×1` 混在一起 →
**短动作 + 相似动作仍然分不开**，这与之前 VLM 的错误结构完全一致（都卡在"分不清物件"）。

## 四、重新规划：四阶段（把 VLM 从"逐段判"降级为"给原型起名"）

### P0 · 数据基建（✅ 已完成）

- 10 Hz 骨架 + 手框 + 手周 ROI 裁图（2679 张）+ 固定区 ROI 裁图（3600 张）
- 本地变化点检测：±2 秒召回 69.6%、误差中位 0.53 秒
- 人工 GT：38 段 / 6 类 / 7 周期（BORIS）

### P1 · 无监督原型发现（本次已跑通雏形，0 成本）

```
10 Hz 骨架 → 特征（速度/开合/间距/高度，按人体高归一）
           → 变化点切段
           → 每段重采样 16 点 + 标准化
           → k-means（k=8 时纯度 78.6%）
           → K 个"动作原型" + 每原型的时间分布
```

**产出**：`api_runs/motifs_k6.json`（每段属于哪个簇）
**下一步改进**：加 ROI 变化强度特征、用 DTW 距离、按"判别性"给特征加权

### P2 · 原型命名（人工只需一次，约 5 分钟）

对每个簇，取 3 张代表帧 + 3 段代表描述 → 你贴一个 SOP 名字（或 `unknown`）。
**这一次劳动覆盖整个数据集**，之后换新视频只做 P1、复用名字。

**这也是 VLM 唯一还需要的地方**：不是逐段判 17 次，而是**每簇 1~3 次**（K≈8 → 约 10~24 次调用，
而且可以只在换产线时做一次）。

### P3 · 学生模型（真正能上 NX 的东西）

用 P1 的原型标签（+ P2 的少量人工修正）训一个轻量时序模型：

```
输入：10 Hz 骨架（50 点）+ 手框几何 + 手周 ROI 特征（MobileNetV3-Small 冻结）
模型：2 层 TCN，输出 K 类
特点：帧级边界（不像 VLM 卡在 4 秒一帧）、3M 参数、量化后 <5MB、可多路
```

**这一步之后就不再需要云端 VLM 了**，VLM 只是"造标签的师傅"。

### P4 · 闭环（展示 + 异常）

- 前端三轨 + 卡片 + BORIS 导出（已有）
- 新增：**周期完整性检查**（每个周期应包含哪些步骤、漏了哪步）
  依据：GT 有 7 个周期，每周期一般 5 步 —— 这是比"逐帧准确率"更贴合业务指标的验收方式

## 六、必须讲清的两个风险

1. **短动作（0.28~0.76 秒）在任何 10 Hz 方案里都很难** —— 它们只占 2~8 帧。
   要么承认"这些段不参与自动判定"（人工补），要么把采样提到 20~30 Hz（算力上升）。
2. **你的 SOP 有 3 对步骤在"动作层面"几乎一样**（取镜座 vs 取上盖、装上盖 vs 装密封塞、
   紧固 vs 系扎带）。原型聚类能分开紧固，但**分不开取镜座/取上盖** —— 因为差别在手里的东西。
   → 这类必须靠 **手周 ROI 图像特征** 进入学生模型（这本来就是原设计的一部分）。
