## `src/` `scripts/` `tests/` — 独立计数模块

| 文件 | 作用 | 入库 |
|---|---|---|
| `src/fastener_counter.py` | 因果状态机 `WAITING → FASTENER_PLACED → FASTENING → COMPLETE / UNKNOWN`。核心价值：**重复按压归并为一次紧固事件**，长遮挡转 `UNKNOWN` 而不是乱计数。有 6 个可调阈值 | ✅ |
| `scripts/count_fasteners.py` | CLI：读 JSONL / CSV 逐帧信号 → 跑状态机 → 写结果 JSON | ✅ |
| `tests/test_fastener_counter.py` | 3 个 `unittest`：重复按压只算一次 / 无放置不计数 / 长遮挡转 UNKNOWN | ✅ |
| `src/style.css` | **孤儿文件**：内容是 `.video-wrap{position:relative}` 与 `.pose-overlay{...}`，Vite **从不加载**它。历史上"骨架贴不到视频上"的排查陷阱就是它。建议删除 | ✅ |

运行单测：

```powershell
.venv\Scripts\python.exe -m unittest discover -s tests -v
```
